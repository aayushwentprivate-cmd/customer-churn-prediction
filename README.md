\# Customer Churn Prediction



A machine learning web application that predicts whether a customer is likely to churn based on their demographic, account, service, and billing information.



The project uses \*\*Scikit-learn\*\* for machine learning and \*\*Streamlit\*\* to provide an interactive web interface for making predictions.



\---



\##  Features



\- Predict whether a customer is likely to churn

\- Display churn and non-churn probabilities

\- Interactive Streamlit interface

\- Handles categorical and numerical customer features

\- Uses a trained machine learning model

\- Pre-trained model and encoders included

\- Clean and user-friendly prediction interface



\---



\## Machine Learning



The project is based on the \*\*Telco Customer Churn\*\* dataset.



The machine learning workflow includes:



1\. Data loading and exploration

2\. Data preprocessing

3\. Handling categorical variables

4\. Feature encoding

5\. Model training

6\. Model evaluation

7\. Saving the trained model

8\. Integrating the model with Streamlit



\### Models explored



\- Logistic Regression

\- Decision Tree

\- Random Forest
